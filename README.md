# Python-Projects
5 python projects that I am proud of making this year

Project Title:
Brainrot Recommendation Generator

Summary:
This Python project is an interactive recommendation program that suggests different 
“Italian Brainrot” characters based on the user’s preferences. The program asks the user questions, provides a 
matching recommendation, and automatically opens an image of the selected character in the web browser.

Key Features:
Interactive question-and-answer system using user input.
Recommends different characters based on preferences like sports or fruit choices.
Automatically opens character images in the browser using Python’s webbrowser module.
Uses lists and functions to organize code efficiently.
Includes proper image source citations and author credits for all referenced images.


Project Title:
Influencer Data Analyzer

Summary:
This Python project analyzes influencer performance data from a CSV file using the pandas 
library. The program filters and displays information about video views, subscriber changes, 
and channel performance trends based on specific conditions.

Key Features:
Reads and processes influencer statistics from a CSV dataset.
Identifies videos with low views (2,000 or fewer) and high views (50,000 or more).
Detects months where the influencer lost subscribers.
Uses functions, loops, and conditional statements to organize data analysis tasks.
Displays selected sections of the dataset using pandas DataFrames for easier viewing and comparison.
